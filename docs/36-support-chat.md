# 店铺客服
顾客登录后进入「消息」。订单详情里的「就此订单联系客服」会把订单放入待发送区。聊天支持文字、订单卡片和最长 60 秒的语音。浏览器需要麦克风授权，远程站点需要 HTTPS。

默认客服席位为空，顾客仍可通过「官方客服」留言。店主可以在「管理控制台 → 客服设置」留空邮箱并保存，暂时收回接待权限。准备接待时，填入一个已激活账号的登录邮箱，该账号就能从「消息 → 打开客服工作台」接待顾客。待回复留言和对应聊天记录会一起交接。进入会话会消除未读标记，回复后才移出待回复列表。

请按项目现有迁移流程应用 `20261124010000_support_chat`。语音存入 MySQL，只能通过鉴权接口读取，备份应与聊天表一起保管。上线前请按店铺约定配置消息保留期限与备份访问权限。

当前单实例 API 使用每标签页独立的在线心跳。指定账号的客服工作台可见时上报，离开页面时撤销；异常中断最长约 45 秒过期，顾客页面约每 2.5 秒更新。消息、已读进度和待回复状态保存在数据库中。

可选环境变量 `SUPPORT_SMTP_URL` 和 `SUPPORT_MAIL_FROM` 分别指定 SMTP 连接和发件地址。配置后，店主可以开启站外提醒。新一轮待回复会话和客服交接会创建提醒任务，邮件仅含工作台入口。投递失败后会重试。请先使用本地测试邮箱验证，再配置正式发件服务。
